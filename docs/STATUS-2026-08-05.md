## 关键实测发现（外部状态，2026-08-05 当天）
1. **token 生命周期**：JWT `exp` 为 10 天，但服务端 ~7–30 分钟内吊销（`token_revoked`）。
   触发因素与 IP 高度相关：跨 IP 访问（静态 PLUS_PROXY ≠ 注册 sid IP）加速吊销；
   建议所有账号级 API 一律走账号自身 `proxy_used`（工具已默认如此）。
2. **切菲国家锁定（新策略，~18:00 起）**：`billing country must match request country`。
   - 概率性：GCP-SG 出口账号可切 PH；Linode 出口（US/SG）被锁。
   - 被锁时降级为账号注册国结算可成功（我们的 geo 探测与 OpenAI 归因一致，-25 SG→SG ✅、-26 US→US ✅）。
   - 0 元路径未死，取决于注册出口 IP 是否放行 PH。
3. **Stripe hCaptcha 挑战**：需要验证的卡（如 451311）confirm 返回 200 + `next_action.use_stripe_sdk.rqdata`，
   Stripe.js 在客户端跑 invisible hCaptcha，headless + 数据中心 IP 下永远不完成（60s/150s/headed 均挂）。
   - WARP（socks5://127.0.0.1:40000）作绑卡代理时 **Stripe Elements iframe 永不 ready**，不可用。
   - 解决方向：住宅 IP（1024proxy 等）或 hCaptcha 验证码服务 key。
4. **卡状态**：`5236860148310644` 已 `card_declined(generic_decline)`；`4513118051684191` 触发挑战（未验证是否有效）。
5. **Pokemon.cli 池**：可用率 100%，出口 SG/US/JP/KR/HK（全部数据中心段），无 PH 出口，无区域钉扎。
